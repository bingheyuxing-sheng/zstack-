# ZStack 批量账户导入油猴脚本

一个用于在 ZStack Cloud 管理界面中批量创建子账户的油猴（Tampermonkey）脚本。支持读取 CSV/TXT/XLSX 文件，通过 GraphQL API 自动完成账户创建，并支持"班级"列自动创建/绑定计费价目。

## 功能特性

- **批量导入**：支持 CSV、TXT、XLS、XLSX 格式文件
- **自动创建计费价目**：模板中的"班级"列直接作为计费价目名称，不存在时自动创建
- **自动绑定**：账户创建成功后自动绑定对应计费价目
- **预览与校验**：导入前展示数据预览，支持学号重复检测、字符校验
- **进度跟踪**：实时显示导入进度条、成功/失败统计
- **错误汇总**：导入完成后汇总显示所有失败项及原因
- **会话自动捕获**：自动从页面请求中捕获 `x-session-id`，无需手动填写
- **纯 JS SHA-512**：内置 SHA-512 实现，兼容 HTTP（非 HTTPS）内网环境

|------|------|

## 安装方法

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 新建脚本，将 `zstack-account-batch-import.user.js` 的全部内容粘贴进去
3. 保存后访问 ZStack 管理页面（如 `http://10.13.0.45:5000/settings/account-information`）
4. 页面右下角会出现工具面板

## 使用方法

1. **确认会话已捕获**：在 ZStack 页面上执行任意操作（如刷新列表），面板顶部会显示绿色"会话已捕获"提示
2. **下载模板**：点击"下载模板"获取 CSV 模板文件
3. **准备数据**：按模板格式填写账户数据
4. **上传文件**：将文件拖入面板或点击选择文件
5. **预览确认**：检查预览表格中的校验结果
6. **开始导入**：点击"开始导入"按钮

### 模板格式

```csv
学号,姓名,密码,班级
xxxx,张三,,一班
```

| 列 | 必填 | 说明 |
|----|------|------|
| 学号 | 是 | 写入 ZStack 账户名称，允许中英文/数字/`_.@-`/空格，≤255 字符 |
| 姓名 | 否 | 写入账户简介（description），≤256 字符 |
| 密码 | 否 | 留空默认使用 `123456`，须为 ASCII 可见字符 |
| 班级 | 否 | 作为计费价目名称，不存在则自动创建；留空使用默认价目 |

### 计费价目逻辑

- 脚本在创建账户前，先拉取所有已有计费价目
- 对模板中出现的班级名，若 ZStack 中不存在对应名称的计费价目，则自动创建（仅设置名称，不设置单价）
- 同名班级只创建一次
- 账户创建成功后，自动调用 `changeAccountBillingsPriceTable` 将账户绑定到对应计费价目

## 配置说明

脚本头部 `@match` 规则当前匹配 `http://10.13.0.45` 及其 5000 端口。部署到其他 ZStack 环境时，需修改：

- `@match` / `@include` 规则中的地址
- 脚本内 `GQL_BASE` 变量（如通过 `location.origin` 自动适配则无需修改）

## 注意事项

- 首次使用需在 ZStack 页面执行过一次 GraphQL 请求（如刷新页面），脚本才能捕获会话 ID
- 导入前请确认面板顶部显示"SHA-512 自检通过"（绿色提示）
- 建议先用 2~3 行小数据测试，确认流程正常后再批量导入
- 创建计费价目仅设置名称，不会设置单价；如需设置价格请在 ZStack 管理界面中补充
- 脚本不会删除已创建的账户或计费价目，重复导入已存在的学号会报错提示

## 环境要求

- 浏览器：Chrome / Edge / Firefox（需安装 Tampermonkey 扩展）
- ZStack 版本：Cloud 4.x（基于实际测试）
- 网络：需能访问 ZStack Web 管理界面
